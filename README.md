# CodeAlpha AI & ML Internship — Task 5
## Decision Trees and Random Forests

This project implements the requirements in Task 5: Decision Tree classification and visualization, overfitting analysis using tree depth, Random Forest comparison, feature importance, and cross-validation.

Dataset: Breast Cancer Wisconsin Diagnostic dataset from scikit-learn.
Samples: 569 | Features: 30

Results:
- Best Decision Tree depth: 2
- Decision Tree test accuracy: 0.8947
- Decision Tree 5-fold CV accuracy: 0.9319
- Random Forest test accuracy: 0.9561
- Random Forest 5-fold CV accuracy: 0.9626

Files:
- decision_tree_random_forest.py
- breast_cancer.csv
- decision_tree.png
- overfitting_analysis.png
- feature_importance.png
- results.txt
- interview_questions.txt
- requirements.txt

pip install -r requirements.txt
